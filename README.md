# Entity Resolution and Golden Record Laboratory

## Project Status

In development.

## Overview

This portfolio project examines how duplicate and inconsistent customer records can be identified, evaluated and resolved to support a trusted enterprise customer view.

The project uses fictitious FEBRL record-linkage data and combines data-quality analysis, SQL, Python, entity-resolution techniques, golden-record design and governance controls.

## Business Problem

Organisations often maintain customer information across multiple systems. Variations in names, addresses and other identifying attributes can create duplicate records, fragmented customer views and unreliable reporting.

## Project Objectives

- Profile the quality of the source data
- Establish a transparent duplicate-detection baseline
- Compare alternative record-matching approaches
- Evaluate matching performance
- Design survivorship and golden-record rules
- Create a manual-review process for uncertain matches
- Present results through dashboards and an interactive application
