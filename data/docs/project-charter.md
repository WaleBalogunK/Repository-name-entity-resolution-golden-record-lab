## Key Questions

1. How serious are the duplicate and data-quality problems?
2. Which fields provide the strongest matching evidence?
3. How well does a rules-based baseline perform?
4. Can more advanced matching improve the results?
5. Which uncertain matches should be sent for manual review?
6. How should conflicting attributes be resolved?
7. What governance controls are required to sustain the golden record?
